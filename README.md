# 내 교통 · Scriptable 버스 위젯

아이폰의 Scriptable에서 정류소와 버스 노선·방향을 선택해 작은 홈 화면 위젯에 표시하는 첫 버전입니다. Xcode가 필요하지 않습니다.

**실제 아이폰과 개인 API 키를 이용한 조회는 아직 검증하지 않았습니다.** 현재는 부천 버스 한 항목과 작은 위젯이 대상이며 지하철·여러 항목·중간 위젯은 지원 전입니다.

## 아이폰에 넣기

1. [Scriptable](https://apps.apple.com/kr/app/scriptable/id1405459188)을 설치합니다.
2. 이 저장소의 **TransitWidget.scriptable** 파일을 다운로드한 뒤 공유 메뉴에서 Scriptable로 열어 추가를 시도합니다. 가져오기 화면이 나오지 않으면 TransitWidget.js 전체를 새 Scriptable 스크립트에 붙여 넣고 이름을 **내 교통**으로 정합니다.
3. 실행 후 필요한 경기버스정보 API 인증키의 Decoding 값을 기기의 보안 입력창에 입력합니다. 키를 GitHub 이슈·소스 코드·대화에 올리지 마세요.
4. 정류소 → 버스 번호와 방향 → **위젯에 표시**를 누릅니다.
5. 홈 화면에 작은 Scriptable 위젯을 직접 추가하고 **내 교통**을 선택합니다. 표시 항목 저장이 홈 화면 위젯을 자동 추가하지 않습니다.

키 발급·상태·오류 처리와 기기 확인 순서는 [설치 안내](INSTALL_IPHONE.md)를 참고하세요. 공유 파일 가져오기와 실제 홈 화면 동작은 실기기 확인이 필요합니다.

## 확인된 것과 남은 것

- JavaScript 자동 검사 55개 통과. API·GPS·Scriptable 저장과 UI는 대역을 사용했습니다.
- 실시간 예측의 조회시각을 보존하고, 정보 없음·운행 종료·회차지 대기·통신 실패를 구분하도록 작성했습니다.
- 도착시간은 **조회 당시의 예측**입니다. 위젯 갱신은 iOS가 결정하며 초 단위 갱신이나 저장 직후 반영을 보장하지 않습니다.
- 실제 부천 API 응답·방향, 앱과 위젯의 파일/Keychain 공유, 위치 거부·통신 실패, 다크 모드·딥링크·타일 요청은 아이폰에서 검증 전입니다.
- 제품 파일은 합성 도착정보를 기본 표시하지 않습니다. 유효한 인증키가 필요하며 이 저장소에는 키가 포함되지 않습니다.
